Final Year Project

SMART ELECTRONIC HEALTH RECORD SYSTEM
WITH INTEGRATED TELEHEALTH

For Klinik Pakar Lawatan (KPL)

A clinic system designed to manage patient health records, telehealth consultations, and specialist visit workflows in one smart platform.

Project Overview

The Smart Electronic Health Record System with Integrated Telehealth is created for Klinik Pakar Lawatan (KPL). It supports patient registration, electronic records, teleconsultations, and specialist appointment management.

This system helps Klinik Pakar Lawatan move from paper-based records to a secure digital environment that improves patient care, reduces waiting time, and streamlines clinic operations.

Objective: Improve clinical record processing and telehealth access.
Scope: Patient records, appointments, teleconsultation and admin reports.
Language: HTML, CSS, JavaScript, PHP.
Platform: Web application with MySQL database backend.

System Overview

System Overview

This application is designed for Klinik Pakar Lawatan (KPL) to manage patient health records, telehealth sessions, and specialist appointments in one system.

  • Patient registration and electronic health records
  • Telehealth consultation booking and management
  • Appointment tracking and specialist visit workflows

The system aims to improve clinic efficiency, reduce waiting time, and keep patient data secure and accessible.
